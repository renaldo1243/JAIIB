# JAIIB Prep

JAIIB study app (Nov 2026): switch between **IE & IFS** and **RBWM**. Each subject has chapter notes, a question bank, a daily spaced-revision quiz and a 100-question / 120-minute mock. Installable web app (PWA); progress is stored on the device, separately for each subject.

- RBWM: 582 practice questions (bank.json, notes.json)
- IE & IFS: 663 recalled PYQs May 2023 – May 2026, keys checked against rules as on 30 June 2026 (bank_ieifs.json, notes_ieifs.json)
